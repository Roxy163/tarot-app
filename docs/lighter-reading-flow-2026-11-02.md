## 产品规则

1. 统一保存不再以文字数量或逐牌填写进度判断完成。录齐牌面即可保存完整记录，整体想法和逐牌解读均可选；真正缺牌的位置仍可保存，并能通过原“待补全”筛选找回。历史 `draft/complete` 不再直接决定展示状态，按实际牌面派生，不批量改写旧记录。
2. 默认主流程为问题、录牌、我的想法、保存。不增加简易/专业等模式选择。原组合解读成为多牌手记的“我的想法”；单牌想法与原逐牌字段同步，清空不会复活旧文字。逐牌研习默认收起，牌面对应按需查看，疑问按需添加，有内容的疑问保留可见。逐牌切换、换牌、正逆位、自由摆牌、撤销和长按均保留。
3. 回看时可直接补写现有 `userFeedback`，不用返回完整编辑表。只更新当前手记的复盘及修改时间，读取最新记录再合并；先确认本机持久化成功，再沿用既有云端队列。保存成功仍留在同一条手记，失败保留输入。日运手记来源复用同一功能，不复制记录、不写入日运抽牌存储。
4. 私人阅读使用独立完整页面，提供返回和原编辑入口。先展示当时的想法与后来的经历，移除学习闭环检查面板和默认待复盘任务标签。逐牌内容、AI 长回答及补充资料按需展开；不重复渲染空白解读提示。有逐牌文字但没有整体想法的旧记录，首屏显示首条原文并注明牌位，不生成或冒充 AI 摘要。公开阅读继续走原公开视图，不能显示私人复盘和编辑控件。
5. 私人典籍网格和列表预览用户原文；有复盘时增加一句后续。只取已有文字，不要求用户再写摘要，也不调用 AI。

## 兼容与保护

- 复盘草稿按账号和手记 ID 独立保存，重开及刷新可恢复；成功保存清理，账号注销清除对应分区。草稿格式做基本类型检查。
- 保存中阻止返回和重复提交。若草稿也无法暂存，离开前确认；普通返回不增加确认负担。恢复原文字后离开会清理无变化草稿，避免复活已删除输入。
- 保存回调核验当前账号与资料加载状态，拒绝旧账号回调、未知 ID、示范记录及非本人记录，不允许创建副本或写入其他账号。
- 新增窄范围复盘更新不清理或修改完整手记的编辑状态，牌面、日期、标签、AI 参照及其他字段保持不变。复盘不加入公开文档，未修改 Firestore Rules。
- 修正多牌手记仅因标签为“日运”就被当作单牌、丢弃整体想法的保存分支。按真实牌数判定，保留原坐标与所有逐牌内容。
- 导师提示词也支持只写整体想法或部分逐牌解读，未填的个人理解不生成空行；全无个人想法时仍提示先写一点。咨询版仍不导出私人解读。此前可编辑提示词、材料开关、复制和草稿保护保留。
