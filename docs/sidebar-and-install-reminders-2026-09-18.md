# 侧边菜单与添加到桌面提醒

状态：2026-09-19 已随广场与开屏改动发布。正式地址：https://tarot-pavilion.pages.dev/ ，生产版本 `13d4552279d8`。部署详情见 `docs/public-square-and-startup-2026-09-19.md`。

## 行为

- 新增统一 `SidebarDrawer`，保留原左上角菜单入口。手机从左侧窄边向右滑，或拖动中部拉手打开；电脑悬停拉手会轻微探出，可点击或拖开。
- 菜单跟随手势，短距离拖动回弹，向左滑动收起。水平意图明确后才捕获指针，保留按钮轻点与纵向滚动；取消、窗口失焦和切后台时释放拖动与滚动锁。
- 抽牌手记页仅显式拉手支持打开手势，避免干扰卡牌/自由画布。其他弹窗打开时隐藏边缘入口。
- 侧栏接入共享焦点管理：Tab 循环、Escape 关闭、关闭后返回入口；使用减少动态效果偏好。
- 添加到桌面提醒改为明确的“不再提醒”，不再按 14 天循环。旧版已关闭过的提醒同样保留关闭选择。
- 菜单里的“添加到桌面”始终保留，可修改提醒偏好，也可选择“我已添加到桌面”。设置保存于当前浏览器，不写入云端用户数据。
- 监听 `appinstalled`，识别独立应用启动，并保存已添加状态。浏览器标签页安装成功后即使显示模式未变，也会记住；同页多个入口共享偏好与原生安装事件的消费状态，避免重复调用。
- 浏览器提供的安装信号并不覆盖所有已有快捷方式，因此保留手动确认。不尝试扫描用户桌面。清除浏览器数据或换浏览器后，本机设置可能需要重新选择。
