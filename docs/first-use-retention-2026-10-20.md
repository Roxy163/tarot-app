# 首次使用体验改进（2026-10-20）

状态：2026-10-21 用户确认提交并部署；发布前复验通过，Cloudflare 授权过期，正在重新授权。正式网站尚未更新。本地预览为 http://localhost:3003/。

## 本轮改动

1. 典籍顶部增加日运数量与复盘入口，复用现有完整日运档案页，不混合两种记录的数据。
2. 首页记录日运及档案补写页显示实际牌面，支持放大查看正逆位；关闭预览不丢输入。
3. 安装提醒增加“稍后”，暂停 24 小时并跨刷新保留；填写手记、设置、账号及牌库页不展示提醒。原有永久关闭、已安装及手动安装入口保留。
4. 日运保存后、典籍最近真实手记旁增加对应牌的研习资料入口；首页牌义注疏显示已有记录的牌数。阅读资料覆盖在来源页上，返回保留筛选、滚动与草稿；首次加载时可见状态并可返回取消。
5. 首页轻提示最近一条往日待回看的日运；可暂时略过，当天当前会话内不再提示，不改写或删除日运。日期按本地日历，账号间隔离。
6. 增加“随机一张”，保留洗牌、选数字、揭牌和现实牌录入流程，不改变手记自由选牌与摆牌。
7. 牌库批量编辑与重置收进“更多”，全局保存仅在元数据有变化时显示。保留“成册”名称、PDF / 表格 / Markdown；导出选项改为短弹窗，修复小屏菜单越界和被裁切的问题。
8. 广场增加独立“示范案例”入口，三个虚构案例展示直觉、解读和回看的关系。明确标示虚构，不写入云端，不计入公开手记，也不冒充用户反馈。
