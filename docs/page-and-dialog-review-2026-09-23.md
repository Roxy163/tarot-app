# 页面与弹窗交互检查

## 判断依据

需要持续填写、多次修改或阅读长内容的功能适合独立页面：不显示底层页面和遮罩，顶部保留返回，系统返回逐层退出，输入与原页面状态保留。删除确认、临时选择、筛选等短操作保留弹窗，减少无意义跳转。

这些页面共用 PageView：不使用 dialog 语义或遮罩关闭；通过独立主内容区域呈现，背景不可点击、聚焦或被读屏访问。页面进入时聚焦标题，避免自动打开键盘；返回复用原关闭保护及顶层交互栈。页面内滚动，顶部返回不随正文移走，来源页面保持挂载。提示消息单独展示，避免被背景隔离影响。

上述核心研习功能本轮完成代码检查，尚未改造；它们需要按完整使用流程分别验收，不能只移除边框或放大弹窗。

## 适合保留的弹窗

- 删除、注销、恢复默认、离开未保存编辑等确认。
- 选牌、正逆位选择、临时预览卡牌等需要保留当前操作上下文的功能。
- 典籍索引、广场筛选、案例操作等短选择。
- 举报：选择原因与简短补充，保留上下文和提交保护。
- 登录提醒、本机记录合并提示等短决策。
