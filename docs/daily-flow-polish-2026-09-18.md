# 日常流程与弹窗键盘体验验收

用户授权先沿日常流程打磨、验收后统一发布；继续完成因额度中断的工作，并补齐原检查清单第六条。

## 本轮改动

- 手机典籍搜索独占一行，避免被工具按钮挤窄；手机直接显示多选入口，选中后可以导出。常用筛选、导出、编辑和关闭按钮补齐 44px 触控面积。
- 典籍默认浏览隐藏红色删除按钮；左滑删除、多选单条/批量删除及确认流程继续保留。
- 修正手记卡片、日运档案卡片在按下时提前捕获指针的问题。仅开始横向拖动后捕获，避免手机点击编辑、补写等按钮被卡片吞掉。
- 手记问题、日期、逐牌注疏、疑问、复盘及搜索等常用输入采用手机 16px 字号；补充输入名称、保持原有森林主题。
- 日运档案补写与首页共享按账号/记录隔离的草稿。关闭或刷新后继续，成功保存才清理，失败保留文字和弹窗。
- 第六条：通用 Modal/ConfirmDialog 已有共享 `useModalFocus`。本轮把选牌器、手记详情、典籍索引、牌义详情、小考档案、牌阵名称冲突提示及日运复盘接入同一机制；去掉重复 Escape 监听和小考独立滚动锁。
- 弹窗补齐名称、对话框语义、焦点进入/返回、Tab/Shift+Tab 循环、只关闭最上层的 Escape。跳过隐藏/禁用/负 tabindex 控件；中文输入法组合输入时不把 Escape 当作关闭弹窗。
- 嵌套选牌搜索改在内层弹窗注册后聚焦，避免外层焦点约束抢走焦点；手机不自动弹出搜索键盘。

- 原有草稿离页/存储失败、牌义跨设备合并/账号切换/删除标记、日期重复编辑测试继续通过。日期测试额外在 America/Los_Angeles 和 Pacific/Kiritimati 下分别通过 7 项。
- Playwright 独立游客会话，实际创建手记、修改复盘、刷新找回、搜索、详情和索引 Escape、多选、下载 PDF/CSV/Markdown。CSV/Markdown 中日期、逐牌解读换行、牌面疑问与复盘内容均核对一致。

- 最终本地浏览器控制台：0 错误、0 警告。截图与导出样本在 `output/playwright/flow-*`。
- 没有扩大为整体重构；原有日期和草稿持久化已抽出，本轮继续复用。未更改云端权限规则或既有记录数据结构。

本轮验证对话框语义与真实浏览器键盘行为，不等于已完成 VoiceOver/NVDA 全量屏幕阅读器认证。云端同步采用已有回归测试，本轮不操作真实用户账号或数据。
