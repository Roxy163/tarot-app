# 广场与开屏体验验收（2026-09-19，本地未部署）

## 改动

- 公开手记卡片、牌例、最近牌阵案例和作者管理列表均可打开完整阅读弹窗。公开阅读隐藏客户资料、私人复盘、AI 参照和编辑入口；匿名分享继续隐藏真实昵称。
- 广场改为轻量内容导航、单行搜索及“筛选”入口。标签、收藏筛选收进筛选窗口；收牌阵、牌例和举报收进“更多”。保留全部原有能力。
- 卡片突出问题、单行摘要和小牌面。手机单列、桌面双列；点赞、收藏和全文入口缩小视觉尺寸，保留至少 44px 的触控区域。内置练习示例不再混入广场。
- 公开详情的问题放进可滚动正文完整显示，长文可读到底。弹窗继续使用统一的焦点管理、Escape 关闭和关闭后焦点返回。
- 新增云端点赞与取消点赞。私有点赞记录与公开总数在事务内一起变更，计数使用原子增减；重复提交同一状态不会重复计票。保存失败不显示成功，已提交后计数刷新失败也不会误报点赞失败。切换账号与迟到响应隔离。
- 启动时改用无外框的品牌标识与“正在加载…”；不再出现“正在恢复账号状态”或模拟进度条。等待 1.2 秒后才说明慢连接，保留原有约 2.2 秒自动本机兜底，不额外增加等待或确认步骤；恢复连接后仍接收真实登录状态。

## 验收证据

- 全量测试：75 个文件、457 项通过，包含本机存储空间不足时收藏保持原状态的回归验证。
- TypeScript 检查与生产构建通过。当前本地 PWA 版本 `13d4552279d8`。
- Firestore 模拟器（仅 `demo-tarot-square`）18 项安全检查通过：游客写入拒绝、跨账号私有记录访问拒绝、单独伪造计数/记录拒绝、重复点赞幂等、并发点赞与撤销计数正确、隐藏后拒绝公众读取及允许本人清理点赞。
- Playwright 独立浏览器：真实公开案例只读加载及详情打开；手机 360/390px 无横向溢出，筛选和更多操作可用，长文滚动到底、Escape 返回原控件；桌面 1440px 双列布局。多案例密度与长文使用独立测试浏览器的本机样例，没有发布测试内容。
- 将登录模块故意延迟 7 秒：显示普通加载及延迟说明后，约 2.6 秒进入可操作应用（包含页面启动时间），无需点击；单元测试另验证正常登录无最短等待、已知账号保持隔离、迟到登录恢复。
- 截图在 `output/playwright/`：`startup-loading-mobile.png`、`startup-slow-mobile.png`、`square-multiple-mobile.png`、`square-multiple-desktop.png`、`square-real-case-detail.png`、`square-long-detail-bottom.png`。多案例截图是验收样例，并非线上分享数量。

## 发布约束

本轮没有部署网站，也没有发布数据库规则。生产仍是项目记忆中的 `93f6d03cedbe`。

点赞新增 `publicReadingReactions/{readingId}`（仅总数）及 `users/{uid}/publicLikes/{readingId}`（仅本人可读）。正式发布时须先发布本次 `firestore.rules`，再发布网站，并验证真实云端点赞/撤销。账号注销也会先清理该账号的点赞，不能将新网站与旧规则混合发布。

目前点赞安全性和并发是在模拟器验证；未向生产写入测试点赞。规则发布前，本地预览连接现有云端时可能提示点赞保存失败，这是服务器拒绝新路径，不代表本机测试已经完成线上验收。
