# 核心研习流程页面化

## 状态与范围

2026-09-29 完成本地实现与浏览器验收，2026-09-30 随 `ab24214` 发布到正式网站。完整发布与线上验收记录见 [核心页面与牌阵发布记录](core-pages-and-spreads-release-2026-09-30.md)。本轮不修改数据库规则、账号权限或公开数据范围。

用户要求日运、牌义和牌阵的持续填写、阅读与编辑使用完整页面，并将这一原则用于后续新功能。实现复用 `PageView`，保留森林主题与原有业务功能，不以放大弹窗代替页面。

## 已完成

| 流程 | 页面与保护 |
| --- | --- |
| 记录日运 / 补写日运 | 完整填写页；保留按账号与记录隔离的草稿，保存成功才清理；草稿本机写入失败时阻止离开 |
| 日运复盘 | 完整阅览页，补写为下一级页面；来源列表保持挂载，保留筛选、滚动位置、导出与牌义例证入口 |
| 牌义详情 / 编辑牌义 | 详情和编辑逐层进入；保留正逆位内容、注疏、批量编辑与草稿；窄屏卡牌信息随表单滚动，底部操作保持可见 |
| 编辑对应 / 灵数注解 | 完整表单；未保存返回需确认，保存失败保留内容，提交中禁用返回与重复编辑 |
| 牌阵工作台 | 完整工作页；保留模板、自由画布、坐标、撤销、保存及恢复默认；放弃修改后恢复原手记和牌阵 |
| 小考档案 | 完整阅览页；保留题型、筛选、答题历史和返回后的原题状态 |

`PageView` 增加普通/宽版与滚动/工作区布局，继续统一处理标题聚焦、背景隔离、来源焦点恢复、系统返回与 Escape。牌义详情在退出动画结束后恢复来源列表位置。删除、恢复默认、未保存确认与临时选牌仍使用弹窗。

同时修复游客灵数保存和恢复默认忽略本机写入失败的问题：失败返回明确结果，保留编辑内容，不再误报成功。

完整页面优先规则已写入 `AGENTS.md` 和项目记忆。公开/私人手记详情不在本轮范围，仍可后续单独处理。
