发布状态：应用提交 `f174fd5` 已于 2026-10-21 推送 GitHub 并发布到原有 Cloudflare、Netlify 正式地址；2026-10-22 完成最终线上复核。以下保留各开发阶段的本地验收记录，最终发布状态见文末。

## 范围

按用户确认的五项顺序处理，不提交、不部署，不改 Firestore Rules 或已确认的牌阵几何基准。

1. 新建手记选择日运主题时，空问题预填“今日抽牌记录”，问题栏始终可编辑；已有问题不覆盖。首页速记入口同样预填。
2. 移除依赖日运标签的清牌副作用。添加、移除或更换标签不重置牌阵、牌面、逐牌解读或原问题。
3. 首页和典籍共享“日运复盘”入口，来源分为“日运抽牌 / 日运手记”。日运手记兼容多标签与旧 category；多牌手记完整查看，支持搜索和复盘状态筛选，编辑原手记后返回原入口。只投影视图，不复制或迁移数据。来源、筛选、搜索和滚动在返回时保留。
4. 典籍搜索覆盖牌名与别称/英文名、牌位、牌阵、标签、逐牌解读、整体解读、复盘、客户反馈及 AI 参照；保留既有客户与索引筛选。
5. 设置新增“备份与恢复”独立页面。JSON 文件包含当前账号的已保存手记、日运、自定义牌阵、牌面资料、注疏、灵数、关键词和练习记录。排除示范手记、登录凭据、账号资料和未保存草稿。

## 备份恢复保护

- 文件版本与内容逐层校验，大小上限 20MB；拒绝损坏文件、重复标识和原型污染字段。对实际旧手记缺少 `interpretation.summary` 补空值兼容。
- 导出前不改资料，选择文件后先预览数量，再单独确认合并。
- 当前已有内容优先，不覆盖同 ID 手记、日运、已存在的牌面/练习资料或注疏删除标记。重复导入不会复制记录。
- 恢复的新增手记绑定当前账号并默认私密，不携带原账号身份、作者权限或监管字段，不会自动发布。
- 自定义牌阵同名但几何不同则另存并映射新增手记；坐标、旋转、大小及顺序不改，官方牌阵不覆盖。
- 多个本机存储项使用写入日志：失败回滚，意外中断在后续读取前恢复；成功持久化后再更新页面状态及沿用原同步流程。
- 登录或同步尚未完成时禁止恢复；异步读取结束重新核验账号与就绪状态。账号切换后不把旧数据写入新账号。
- 后续检查已替换原先“整包导出前必须联网读取灵数”的限制：默认导出当前账号本机已保存资料和灵数缓存，无需等待云端。文件标注灵数来源与最近完整云端读取时间，不能把缓存称为全云端备份；可单独读取云端灵数，8 秒超时或失败不阻断本机导出。恢复的灵数本机持久化后排队同步；现有云端值优先，失败保留队列，注销账号时清除本账号队列及缓存。

## 第二轮留存修复

用户再次检查后同意追加以下六项，仍只做本地预览，不提交、不部署：

1. 日运抽出即先可靠写入本机，成功后才揭示；所有已保存抽牌立即出现在复盘入口，包含旧的未手动归档记录。跨天未回看提醒不再要求先写文字。保留原有重抽、现实牌、第一直觉及复盘逻辑。
2. 缩减牌阵会先检查将移除的位置是否含牌面、逐牌解读或疑问，有内容才确认。最近五次牌阵切换保留独立前后快照，可撤销恢复，草稿重开后仍可撤销。撤销若会覆盖切换后的新修改，再次确认。恢复牌面、正逆位、坐标、旋转、大小、文字、焦点及原撤销历史；不改自由选牌与任何牌阵几何基准。
3. 本机导出与云端同步解耦。当前账号 React 资料尚未就绪时，读取该账号明确分区的本机缓存，不读上一账号状态；合并恢复仍等待就绪并在写入前重新核验账号。灵数读写缓存及导入队列均按账号隔离，读取失败不清空缓存。可选云端读取允许返回，重开可重试，迟到响应不会改新页面状态。
4. 反馈附件在当前软件会话中跨页面保留，主动移除或发送成功才清空；账号变化则清除附件并使旧异步结果失效。明确说明刷新或关闭浏览器后须重新添加，未将截图写入浏览器持久存储。
5. 广场空状态“去记录一条”改为真实按钮，打开原手记编辑器；不自动勾选公开。
6. 首页在有实质未完成内容时显示“继续上次记录”，恢复新手记或已保存手记的修改草稿。只查当前账号和真实手记 ID；排除空白、默认日运标题、未修改及已删除记录。保存或主动取消后消失。

## 逐项复核与补齐

用户要求重新核实今天承诺的改动是否真正完成。本次重新对照两轮共 11 项，补齐以下四类遗漏，仍不提交、不部署：

1. 旧版编辑草稿缺少 `hasUnsavedChanges` 时，打开后被错误标为未修改，首页续写入口消失。现在保留旧草稿的续写资格；新版本仅打开已保存手记仍不产生续写提示。
2. 灵数缓存写入失败时，原先会误报刷新成功，或提前清除导入队列。现在完整云端读取只有本机持久化成功才算完成；同步、显式保存和重置均先确认缓存写入，再清除导入队列。失败保留原资料，并允许稍后重试。
3. 现实牌录入保存失败的提示原先在选牌弹窗背后。现在直接显示在弹窗内，选牌器保持打开，恢复存储后可直接重试。
4. 从首页日运复盘编辑手记，保存后再返回会误入典籍。现在保存和取消都回到原入口，保留日运来源、筛选及滚动；从典籍进入时也不再清空典籍搜索条件。
